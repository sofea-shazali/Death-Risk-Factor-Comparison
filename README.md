# Death-Risk-Factor-Comparison
This project focuses on the death risk factors between Malaysia and its neighboring countries - Indonesia, Thailand, Singapore, Brunei, and Philippines.
These countries were chosen to see the similarities and differences between neighbours.

**Data Cleaning:** Uses forward fill for missing values

**EDA:** Identify the death risk factor for each year and the most common factor
Data visualization: Bar charts and line plots to see the relationship and trends clearly

Data Science Questions:
1. For each year, what factor contributes the most
2. What is the most common factor
3. How do risk factors trend over time for different countries
4. Is it possible to cluster these countries based on risk factor
